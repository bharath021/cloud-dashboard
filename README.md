# ☁️ Cloud Dashboard (FastAPI + React)

This project is a full-stack AWS Cost Tracking Dashboard built with:

- 🖥️ **Frontend**: React + Chart.js
- ⚙️ **Backend**: FastAPI (Python)
- 📊 **Visualization**: Pie + Bar Charts + Monthly Breakdown
- 🌗 **Features**:
  - Search by service
  - Dark/Light mode toggle
  - Month selector
  - Total AWS spend summary

## 🏗️ How to Run Locally

### Backend (FastAPI)
```bash
cd cloud-dashboard-backend
pip install -r requirements.txt
uvicorn app.main:app --reload
######Frontend (React)
cd frontend-dashboard
npm install
npm start
